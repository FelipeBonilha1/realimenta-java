Protótipos estáticos das telas ligadas à API. Servem para o PDF e para a apresentação. Não enviam dados e não estão integrados ao Spring Boot.

Demonstração visual. Os botões não chamam a API. Os números repetem o roteiro fictício do script de demonstração.
